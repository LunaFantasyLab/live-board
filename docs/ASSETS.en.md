# Asset provenance

[简体中文](ASSETS.md) | **English**

This repository contains no original assets taken from games, films or other works (textures, fonts, logos, characters, UI screenshots, or 1:1 copies of interface elements).
Everything you see is generated by the code in this repository; the only bundled third-party asset is the free Anton font (SIL OFL 1.1).

| Asset | Location | Source | License |
|---|---|---|---|
| Desk 3D model `studio6.glb` | `board/public/` | Built by `blender/build_studio.py` from cubes, cylinders, spheres, cones and procedurally computed star polygons, vertex colors only, no textures; compressed by `blender/export_web.sh` (meshopt + quantization). Can be regenerated with Blender 4.2 | This project (CC BY-NC 4.0) |
| Generator scripts | `blender/` | Written for this project; they load no external images, fonts or models | This project |
| Web icon (favicon) | inline SVG in `board/index.html` | A rounded square with an outline, written in code | This project |
| Background rays, halftone dots, slanted cards, star badges | `board/src/style.css` | CSS gradients and `clip-path` polygons written in code; no external images, no `url()`, no `@import` | This project |
| Palette (red / black / white / off-white / grey) | `board/src/style.css`, `build_studio.py` | Hand-picked color values | This project |
| The "Z" letters, confetti and light flicker in the scene | `board/src/scene.js` | Generated at runtime with canvas and three.js code | This project |
| Number font Anton | npm `@fontsource/anton`, bundled into `dist` at build time | Google Fonts / The Anton Project Authors | SIL OFL 1.1, see `third_party/licenses/Anton-OFL-1.1.txt` |
| Chinese and fallback fonts (PingFang SC, Noto Sans CJK SC, etc.) | CSS font names | Only refers to system fonts already on the user's computer; not distributed with the repository | — |
| 3D engine three.js | npm `three` | three.js authors | MIT, see `third_party/licenses/three.js-MIT.txt` |
| README screenshots and animations | `docs/images/` (Chinese UI) and `docs/images/en/` (English UI) | Recorded in a browser using this repository's board page, the fake Notion in `tests/` and the example rosters; no real data | This project (CC BY-NC 4.0) |

Regenerate the model:

```bash
BLENDER=/path/to/blender bash blender/export_web.sh
```
